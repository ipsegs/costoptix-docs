<Info>
  Tag Explorer is available on **Professional**, **Business** and **Enterprise**.
</Info>

## Overview

Tag Explorer shows a cloud account's spend by tag. Pick a key such as `env` and you see what `env=production`, `env=staging` and every other value cost, plus what has no value at all. On GCP, tags are called labels and work the same way.

It works one account and one tag key at a time. To roll a team's tagged spend up across clouds, use [Ownership](/features/ownership).

---

## Using it

1. Pick an account in the top navigation.
2. Choose a date range: last 7 days, last 30 days, this month, last month, or custom.
3. Click a tag key in the left panel. CostOptix loads the cost of each value.
4. Click a value to see the resources tagged with it: name, ID, type, location and, on Azure, resource group. Search, filter and page through large lists.

For each key you see:

| Column | Meaning |
|---|---|
| Tag value | For example `production` |
| Total cost | Spend on resources with that value in the period |
| Share | The value's share of the key's total |
| Untagged | Spend on resources with no value for this key |

Both the breakdown and the resource list export to CSV.

---

## Untagged spend

Untagged spend is shown as its own row, not hidden. It is the fastest way to find resources nobody can be held accountable for.

---

## Where the data comes from

Keys load when you open the page. The cost of a key is only fetched when you click it, so the page stays fast.

| Provider | Keys | Costs |
|---|---|---|
| Azure | Consumption Tags API | Usage Details API, scoped to the key |
| AWS | Tag aggregates synced from Cost Explorer | Same aggregates |
| GCP | Labels in the BigQuery billing export | BigQuery query over the export |

<Note>
  On AWS, a tag key only appears after you activate it as a cost allocation tag in the billing console. See the [AWS guide](/providers/aws). Azure and GCP need no extra setup.
</Note>
